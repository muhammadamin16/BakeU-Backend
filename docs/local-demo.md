# BakeU на ноутбуке

Подготовьте Docker Desktop (или Docker Engine), Go 1.26.4, Node.js 24, Bash и OpenSSL. На Windows выполните команды в WSL2 с Docker Desktop integration. Разместите обновлённые `BakeU-Backend` и `BakeU.UZ` в одной папке. Если каталоги называются иначе, задайте абсолютный путь к frontend через `BAKEU_FRONTEND_DIR`.

Из каталога `BakeU-Backend` выполните:

```bash
bash scripts/local-demo.sh prepare
```

Первая подготовка скачает образ MongoDB и зависимости. Скрипт наполнит отдельную базу `bakeu_local_demo`. Повторный запуск добавит отсутствующие тестовые записи и сохранит сделанные вами изменения. Все имена, адреса, email и телефоны в наборе вымышлены.

Откройте два терминала в `BakeU-Backend`. В первом запустите API, во втором Vite.

```bash
bash scripts/local-demo.sh api
```

```bash
bash scripts/local-demo.sh web
```

Откройте `http://127.0.0.1:5173/#/profile`. API доступен на порту 8080, MongoDB на 27017. При конфликте можно задать `BAKEU_LOCAL_API_PORT`, `BAKEU_LOCAL_WEB_PORT` и `BAKEU_LOCAL_MONGO_PORT` одинаково во всех терминалах. Другой порт MongoDB создаёт отдельный локальный контейнер.

Получите пароль тестовых аккаунтов.

```bash
bash scripts/local-demo.sh password
```

| Что проверить | Email |
| --- | --- |
| Кабинет магазина, товары и входящие заказы | `seller01@bakeu.test` |
| Корзина и заказ от покупателя | `buyer02@bakeu.test` |
| Серверная админка | `buyer01@bakeu.test` |

Можно также создать свой email-аккаунт на странице входа. Для заказов укажите номер в международном формате. Режим продавца требует отдельный вход. Для нового магазина понадобится отправить заявку с логотипом, затем одобрить её из тестовой админки. Ссылки «Стать покупателем» и «Войти в магазин» переключают аккаунты. После обновления вкладки войдите снова.

Проверьте товар на витрине, сохраните количество в корзине и оформите самовывоз или доставку на будущее время по Ташкенту. Заказ появится у покупателя, продавца и администратора. В админке `/#/admin` откройте «Покупатели» → «Посмотреть заказы». Статистика учитывает завершённые заказы по дате завершения. Для недели берутся семь дней до выбранной даты включительно, для месяца — выбранный календарный месяц.

## Telegram

Для реального Telegram запустите третий процесс с токеном отдельного тестового бота и своим числовым Telegram ID в `ADMIN_IDS`. Передавайте эти переменные через локальную среду. API и бот автоматически используют один локальный ключ интеграции.

```bash
bash scripts/local-demo.sh bot
```

Бот получает обновления Telegram через интернет, а к Go API обращается на ноутбуке. Для проверки привязки откройте полученную ссылку в браузере на том же ноутбуке. Для запуска Mini App с другого устройства Telegram требуется доступный этому устройству HTTPS-адрес. Проверка витрины, заказов и админки в браузере работает без запуска Telegram.
